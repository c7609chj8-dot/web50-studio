# PROJECT 50 | Next.js 홈페이지 프로젝트 스튜디오

50개 홈페이지 아이디어를 소개하고 진행 상태를 관리하는 Next.js 15 + TypeScript 사이트입니다.

## 시작하기

필요 환경: Node.js 20 이상, npm

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 기능
- 50개 프로젝트 데이터, 10개 분야별 탐색
- 키워드 검색, 유형·분야·상태 필터
- 대시보드: 전체/개발 중/완료/진행률
- 프로젝트 상세: 핵심 기능·난이도·상태·GitHub URL·배포 URL·메모
- 프로젝트 현황 CSV 내보내기(한글 엑셀 호환 BOM 포함)
- 12개월 5단계 로드맵
- PC·태블릿·모바일 반응형 레이아웃
- 로컬 브라우저 저장(localStorage)

## 배포
1. 새 GitHub 저장소 `website-50-studio` 생성
2. 이 프로젝트 폴더의 소스코드 업로드 (`node_modules`, `.next` 업로드 금지)
3. Vercel에서 저장소 Import → Next.js 감지 → Deploy

## 중요한 제한사항
- 현재는 **프로젝트 관리·쇼케이스 MVP**입니다. 50개의 개별 홈페이지 자체를 구현한 것은 아닙니다.
- 상태·URL·메모는 브라우저 localStorage에만 저장되고 여러 기기에서 공유되지 않습니다.
- 로그인·관리자 인증·Supabase·실제 결제·외부 AI API는 연결하지 않았습니다.
- 임의 입력 URL은 링크로 열리므로 사용자 스스로 링크를 확인하세요. 공개 다중 사용자 서비스를 만들 때는 URL 검증과 접근 제어를 추가해야 합니다.
- 현재 robots 설정은 index:false입니다. 대외 공개 포트폴리오로 전환할 때 `app/layout.tsx`에서 SEO 설정을 검토하세요.
- 구글 폰트는 네트워크에서 로드되며, 로딩에 실패하면 시스템 폰트로 대체됩니다.
- 사용 중인 Next.js 버전의 지원 및 보안 업데이트는 배포 전 공식 공지를 기준으로 최신 패치 버전으로 갱신하세요.

## 단계별 발전 방향
1. 현재 MVP를 GitHub/Vercel 배포
2. 프로젝트 상세 개별 페이지(`/projects/[slug]`) 및 작품 이미지 추가
3. Supabase Auth + DB + RLS로 사용자·관리자 권한 구축
4. 프로젝트 기록 다중 기기 동기화, 파일 업로드, 관리 로그 구축
5. 50개 완성 사이트의 실제 URL/스크린샷 등록 및 공개 포트폴리오 전환
